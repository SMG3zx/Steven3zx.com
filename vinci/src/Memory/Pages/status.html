Backup and restore

Snapshot export and restore are administrative operations. Export through authenticated GET /v1/admin/export, validate offline with RESTORE_DRY_RUN=1 vinci memory restore snapshot.json, and restore only after review with RESTORE_CONFIRM=RESTORE_PERSONAL_MEMORY.

The web interface does not perform an implicit graph restore. Use a native Neo4j dump for disaster recovery and keep exported snapshots protected like the underlying memory.
